AI Body Language Decoder using Mediapipe
About the Project

Body language is a huge part of communication — our gestures, posture, and expressions often say more than words. This project uses Google’s Mediapipe framework and machine learning to decode those nonverbal signals. The goal is to give users insights into how they present themselves, which can be helpful in areas like human-computer interaction, communication coaching, and social robotics.

 What I Built

A Streamlit-based web app where users can upload input (video/images) and instantly see predictions.

Integrated Mediapipe’s pose estimation and gesture recognition to detect body posture, hand movements, and facial expressions.

Built an ML pipeline: data preprocessing → model training → evaluation → deployment.

Created real-time predictions with an easy-to-use UI so non-technical users can benefit too.

 Why This Matters

Nonverbal communication makes up a large part of human interaction. With AI, we can analyze these signals to make apps more empathetic and responsive. From virtual assistants that understand your mood to robots that respond to your gestures, this technology opens up new possibilities.

 Tech Stack

Python

Mediapipe for pose & gesture recognition

Streamlit for the web application

TensorFlow/Keras for model training

NumPy, Pandas, Matplotlib for preprocessing and visualization

 Use Cases

Human-Computer Interaction: Apps that respond to emotions and gestures.

Communication Coaching: Improve presentation and communication skills with feedback on posture and expressions.

Social Robotics: Robots that can better understand and react to human body language.
